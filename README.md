# The International Center for Religion & Diplomacy (ICRD)'s AI & Religion Social Network Analysis (AIR-SNA) project.
This repository facilitates data sharing and enrichment for ICRD's AIR-SNA project. The objectives of AIR-SNA are twofold. First, mapping out the *events* that center around artificial intelligence and religion, and second tracking which themes these events touch on over time.
## Guide to the repository
There are several folders that host the two prongs of the AIR-SNA project.
First, the Social Network Analysis (SNA) folder includes the most recent export of the nodes (people, organizations, and events) and edges (connections between nodes).
Second, the Thematic Network Analysis (TNA) folder is home to data relating to tracking themes, topics, and attitudes expressed by pre-event information, e.g., event schedules and webpages.
